4

Turn on GitHub Pages

This is the one step that publishes the website. It only needs to be done once.

  1. Click ⚙ Settings in the top menu of the repository.
  2. In the left sidebar, scroll down and click Pages.
  3. You will see a section called Build and deployment.
  4. Under Source, the dropdown says "Deploy from a branch" — leave it as is.
  5. Under Branch, click the dropdown that says "None". Select main.
  6. The second dropdown next to it says / (root) — leave it as is.
  7. Click the Save button.
Pages settings should now look exactly like this:
Source:  Deploy from a branch
Branch:   main    / (root)    Save
⏳ Wait 3–5 minutes after clicking Save.
GitHub is building the website in the background. Do not close the tab.
After 3 minutes, refresh the Settings → Pages page.

When ready, a green banner appears at the top of the Pages settings page:

✅  Your site is live at https://dmcssajorhat-del.github.io/Rajoi-Bagan-LP-school

How to update the website in future

📋 Add a notice

Add a row to the School Notices Google Sheet. Appears on the website within 1–2 minutes. No GitHub needed.

📝 Change any text

Go to the repository → click index.html → click the ✏️ pencil icon → make the change → click Commit changes. Live in ~1 minute.

🖼️ Replace a photo

Go to the repository → Add file → Upload files → upload the new image with the exact same filename → Commit changes.

📊 New year's enrolment

Open index.html in the repository. Click ✏️. Find the enrolment: table. Add one line at the bottom. Commit. Chart and all figures update automatically.
