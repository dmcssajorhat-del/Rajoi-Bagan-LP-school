Notice Board — Technical Reference

This file is for whoever maintains the website — not for daily notice-publishing. The live site's "Manage notices" panel is kept simple on purpose. This page holds the one-time setup details, in case the Google Sheet connection ever needs to be reconnected or redeployed.

Already working? If Chrome shows live notices correctly right now, you don't need anything on this page. Keep it only for future reference.

Current setup

  • Google Sheet columns (row 1): Date | Title | Details | For | ID
  • Admin passcode is set in index.html → CONFIG → noticesAdminPasscode
  • Live Sheet URL is set in CONFIG → noticesSheetUrl

Known limitation

Firefox blocks this specific Google Apps Script technique due to a strict CORS/redirect security rule Firefox enforces (confirmed via Console: "CORS header Access-Control-Allow-Origin missing, Status 302"). Chrome, Edge, Safari, and mobile browsers are unaffected. This is a known limitation of Google Apps Script itself, not a bug in the website. Use Chrome to manage notices; other visitors safely see the site's fallback notices if their browser can't connect.

If the Sheet connection needs to be redeployed

  1. Open the Google Sheet → Extensions → Apps Script
  2. Delete everything in the editor, paste the script below
  3. Change RAJOI2026 to match noticesAdminPasscode in CONFIG
  4. Deploy → Manage deployments → ✏️ → Version: New version → Deploy
  5. The Web app URL does not change — no need to touch noticesSheetUrl again
function doGet(e) {
  var action = (e.parameter.action || "list");
  var callback = e.parameter.callback;
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var result;

  if (action === "list") {
    var rows = sheet.getDataRange().getValues();
    var out = [];
    for (var i = 1; i < rows.length; i++) {
      if (!rows[i][1]) continue;
      out.push({
        id: rows[i][4] ? String(rows[i][4]) : String(i),
        date: fmtDate_(rows[i][0]), title: rows[i][1],
        details: rows[i][2], "for": rows[i][3]
      });
    }
    result = out;
  } else if (action === "add" || action === "delete") {
    if (e.parameter.passcode !== "RAJOI2026") {
      result = { ok:false, error:"wrong passcode" };
    } else if (action === "add") {
      var id = Utilities.getUuid();
      sheet.appendRow([e.parameter.date, e.parameter.title, e.parameter.details, e.parameter.for_, id]);
      result = { ok:true, id:id };
    } else {
      var rows2 = sheet.getDataRange().getValues();
      for (var j = 1; j < rows2.length; j++) {
        if (String(rows2[j][4]) === String(e.parameter.id)) { sheet.deleteRow(j + 1); break; }
      }
      result = { ok:true };
    }
  } else {
    result = { ok:false, error:"unknown action" };
  }

  var json = JSON.stringify(result);
  if (callback) {
    return ContentService.createTextOutput(callback + "(" + json + ")")
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(json).setMimeType(ContentService.MimeType.JSON);
}
function fmtDate_(v){
  if (Object.prototype.toString.call(v) === "[object Date]")
    return Utilities.formatDate(v, "GMT", "yyyy-MM-dd");
  return String(v);
}

Monthly safety net

Once a month, open "Manage notices" in Chrome, publish any pending notices, and consider asking whoever maintains the site to update the fallback notices baked into CONFIG → noticesFallback, so anything shown to a blocked visitor stays reasonably current.
