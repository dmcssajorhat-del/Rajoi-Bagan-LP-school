3

Upload all the files

After creating the repository, GitHub shows an empty page. Look for the link that says uploading an existing file and click it.

⚠️ Important — select files, NOT the folder
Open your school website folder in File Explorer. Press Ctrl+A (Windows) or Cmd+A (Mac) to select all 25 files inside the folder. Then drag them into the GitHub upload box. Do NOT drag the folder itself — GitHub needs the individual files.

The page shows a blue upload box. Drag all 25 selected files into it. You will see each file name appear as it uploads. Wait for all files to finish — it may take 1–3 minutes depending on your internet speed.

After all files appear, scroll down to find:
Commit changes
Add school website files (25 files)
Leave the description blank. Keep "Commit directly to the main branch" selected.
Commit changes

Click Commit changes. GitHub saves all your files.

✓ Success — You should now see a list of all 25 files in the repository. If you see index.html and the images listed, the upload worked.
4

Turn on GitHub Pages

This is the step that makes the website go live. It only needs to be done once.

  1. Click Settings in the top menu of the repository page (the gear icon).
  2. In the left sidebar, scroll down and click Pages.
  3. Under the heading "Build and deployment", find the Source dropdown. It currently says "Deploy from a branch" — leave it as is.
  4. Under Branch, click the dropdown that says "None" and select main.
  5. The folder dropdown next to it should say / (root) — leave it as is.
  6. Click the Save button next to it.
Your Pages settings should look like this:
Source: Deploy from a branch
Branch: main   / (root)   Save
⏳ Wait 2–5 minutes
After clicking Save, GitHub needs a few minutes to build the website. Do not close the tab. Refresh the Settings → Pages page after 2 minutes.

When it is ready, a green banner appears at the top of the Pages settings:

✅  Your site is live at https://your-username.github.io/rajoi-bagan-school

How to update the website later

The website is now live. Here is how to make changes in the future without any technical help.

📋 Add a notice

Open Google Sheets, add a row to the School Notices sheet. The website updates automatically within 1–2 minutes. No GitHub needed.

📝 Change text or a photo

Go to your repository on GitHub. Click the file name (e.g. index.html). Click the ✏️ pencil icon. Make the change. Click Commit changes. Live in 1 minute.

🖼️ Replace an image

Go to the repository. Click Add file → Upload files. Upload the new image with the exact same filename. Click Commit changes. The old image is replaced.

📊 Add next year's enrolment

Open index.html in the repository. Click ✏️. Find the enrolment: table. Add one new line at the bottom with the new year's figures. Commit. The chart updates automatically.
