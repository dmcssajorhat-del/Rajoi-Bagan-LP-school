Running the school website

Rajoi Bagan LP School · one page · keep near the office table

There are only two jobs. Both can be done on a phone.

Put up a notice, and check who has asked about admission. Nothing else needs doing. The website runs by itself and costs nothing.

1To put up a notice

  1. Open the Google Sheets app on the phone.
  2. Open the sheet named School Notices.
  3. Go to the first empty row and fill in four boxes:
DateTitleDetailsFor
2026-08-14Holiday on 15 AugustFlag hoisting at 8 am. No classes.All classes

That is all. In one or two minutes it appears on the website by itself. Write the date in that order — year, month, day — so the newest notice stays on top.

To remove an old notice: delete that row.

2To see admission enquiries

When a parent fills the form on the website, an email comes to the school Gmail at once.

  1. Open Gmail — the message says a new response has arrived.
  2. Or open the Google Forms app → Responses to see the full list any time.
  3. Call the parent back and note it in the admission register as usual.

The list is saved forever. Nothing is lost if the phone is changed.

3Once a year, after the UDISE return

When the new year's enrolment figures are filed, one line is added to the website file so the chart and the class numbers stay correct. This takes about ten minutes on a computer.

Ask the teacher who handles UDISE, or the person who set up the website. If nobody does it, nothing breaks — the website simply keeps showing last year's figures.

4Important things to remember

  • Use the school's own Gmail account for the Sheet and the Form, not a personal one. Then it stays with the school when people change.
  • Give the password to two people only — the Head Master and one senior teacher.
  • Never write a child's full address, phone number or photograph in the notice sheet. It is a public page. Names of classes are fine; personal details are not.
  • Keep a copy of the file index.html in Google Drive. If anything is ever lost, that one file is the whole website.
