2

Create the Apps Script project

Go to sheets.google.com, click + Blank to make any new spreadsheet — its only job is to host the script, so the name doesn't matter.

In that new sheet: Extensions → Apps Script. A code editor opens with some placeholder text — select it all (Ctrl+A) and delete it.

3

Paste the script and add your token

Go to your website → 🔒 Manage notices → unlock with the passcode → scroll down → Set up one-click publishing → 📋 Copy script. Paste it into the empty Apps Script editor.

Untitled project
var GITHUB_OWNER = "dmcssajorhat-del"; var GITHUB_REPO = "Rajoi-Bagan-LP-school"; var GITHUB_PATH = "notices.json"; var PASSCODE = "RAJOI2026"; // ← change this line function doGet(e) { // ...reads the passcode, then adds or deletes a notice }

Find the line with "RAJOI2026" near the top and change it to match whatever noticesAdminPasscode is set to in your website's CONFIG.

Now add your token from Step 1, kept separately and safely:

  1. Click the ⚙️ Project Settings icon in the left sidebar
  2. Scroll to Script Properties → Add script property
  3. Property: GITHUB_TOKEN   Value: paste your github_pat_... token
  4. Click Save script properties
✓ Why this is safer than before
The token lives only here, inside Google's own servers — never inside the website's code, never visible to anyone visiting the site. Even if someone views your website's source code, this key is nowhere in it.

Click the 💾 save icon, name the project something like "Notice Publisher".

4

Deploy as a Web App

Deploy → New deployment → gear icon next to "Select type" → Web app.

  • Execute as: Me
  • Who has access: Anyone

Click Deploy. Approve the permissions when Google asks — choose your account, click Advanced if it warns the app isn't verified, then Go to Notice Publisher (unsafe), then Allow. This warning is normal for any script you write yourself.

5

Copy the Web app URL into the website

After deploying, copy the link shown — starts with https://script.google.com/macros/s/.../exec.

  1. Open index.html from the website's files
  2. Find noticesPublishUrl: "" near the top of CONFIG
  3. Paste the link between the quotes
  4. Save the file, then upload it to GitHub once — Add file → Upload files → Commit changes
✓ How to know it worked
Open the website, unlock Manage notices. If you see just one clean 📢 Publish notice button — no Download button, no setup warning — the connection is live. Publish a test notice and check it on a different device after a minute.
6

When the token eventually expires

Fine-grained GitHub tokens expire after the period chosen in Step 1 (commonly up to a year). When it does, publishing will simply stop working one day — nothing breaks badly, "Publish notice" just starts showing an error.

To fix it: repeat Step 1 to generate a fresh token, then repeat the small part of Step 3 that updates the GITHUB_TOKEN Script Property — the rest of the setup (the script, the deployment, the website) stays exactly as it is.
